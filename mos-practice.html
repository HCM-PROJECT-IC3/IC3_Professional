Cách làm:

  1. Tải file đề bài (file Office thật) về máy.
  2. Mở bằng Microsoft Office thật trên máy bạn, hoàn thành từng Task bên dưới.
  3. Lưu file, rồi tải file đã làm lên đây để hệ thống chấm điểm.

ℹ️ File bạn tải lên chỉ được đọc ngay trong trình duyệt của bạn để chấm điểm — KHÔNG gửi lên bất kỳ server nào. Hệ thống chỉ lưu lại điểm số + chi tiết đúng/sai từng Task.
